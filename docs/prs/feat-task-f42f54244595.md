# PR Summary: feat/task-f42f54244595

## Summary

- Backlog tasks name the sprint they were moved back from (`carried_from`), for the design's "carried from sprint N" in the Filed by column.

## Scope

- `read_backlog` adds `carried_from: {id, title} | null` to each task, in `GET /projects/{id}/backlog` and `foreman backlog list --json`.
- One store statement (`OverviewStore.backlog_unplanned_origins`) reads the latest `human.task_unplanned` event per backlog task; no query per task.

- `foreman/backlog.py`, `foreman/store/overview.py`
- `tests/test_backlog.py`
- `docs/ARCHITECTURE.md`, `docs/prs/feat-task-f42f54244595.md`

## Risks

- The origin is read from audit events, so a task unplanned before the event existed has null. Events are scanned per project's backlog tasks only.

## Tests
